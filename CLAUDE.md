## Project Overview

Gemini Deep Research Agent - An interactive Python CLI for conducting deep research using Google's Gemini API (`deep-research-pro-preview-12-2025` model). Supports web-only research or combined web + proprietary document search via file search stores.

## Running the Agent

```bash
# Direct execution (uses shebang to venv python)
./deep_research.py

# Or explicitly with python
python deep_research.py

# Debug mode (verbose event logging)
DEBUG=1 ./deep_research.py
```

**Modes:**
- **A (Web Only)**: Internet search only
- **B (Web + Files)**: Internet + uploaded documents via Gemini file search stores
- **C (Resume)**: Continue a previous research session by interaction ID

## Architecture

Single-file Python script (`deep_research.py`) with three main components:

1. **File Search Store Management** (lines 30-166): CRUD operations for Gemini file search stores - list, create, upload files, select stores
2. **Deep Research Interaction** (lines 168-346): Streaming research execution with real-time progress, thought summaries, and follow-up conversation support
3. **Resume/Continue** (lines 348-466): Retrieve and reconnect to previous research sessions by interaction ID

**Key Flow:**
- `main()` → mode selection → `stream_interaction()` → `save_report()` → `follow_up_chat()`
- Reports saved as markdown files in the script directory with topic/timestamp naming

## Dependencies

- `google-genai` SDK (imported as `from google import genai`)
- Python virtual environment at `~/.venv/`

## Output Files

Research reports are saved as `{sanitized_topic}_{timestamp}.md` in the project directory. Resumed sessions use prefix `resumed_v1_...`.

## Web UI

A modern web interface is available in `gemini-research-ui/`. See `gemini-research-ui/CLAUDE.md` for details.

```bash
cd gemini-research-ui
bun install
bun run dev  # http://localhost:3000
```

Features: Real-time streaming, follow-up chat, history management, file stores, stunning Aceternity/Magic UI effects.
